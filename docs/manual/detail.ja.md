# CalcArc 詳細マニュアル

最新の PDF（画面写真つき）は GitHub の Releases にあります: https://github.com/terapyon/CalcArc/releases

## 1. はじめに

CalcArc は、ブラウザで動く計算ツールです。https://calc.terapyon.net/ で開きます。
インストールは要りません。ホーム画面に追加すると、アプリのように開けます（7 章）。

画面のいちばん上の 4 つのタブで、画面を切り替えます。

| タブ | できること | この本の章 |
|---|---|---|
| 【Scientific】 | 関数電卓 | 2 章 |
| 【Convert】 | 単位の換算 | 3 章 |
| 【Scale】 | データ量・LLM のメモリ・データ転送の見積もり | 4 章 |
| 【Finance】 | ローンと複利の計算 | 5 章 |

### 無保証であること

> **計算結果は無保証です。重要な判断の根拠にしないでください。**
>
> このツールは Apache License 2.0 で提供され、同ライセンスの定めるとおり、
> 明示・黙示を問わずいかなる保証も伴わない。

画面のいちばん下にも「計算結果は無保証です。」と出ています。

### 入力をサーバへ送らないこと

> 計算は端末内で完結し、サーバへ送信しない。

### 版の見方と、変更点の在りか

画面のいちばん下に「CalcArc」と版数が出ています。押すと GitHub の CalcArc の
ページが開きます。この PDF の版数は、ファイル名に入っています。

  （日本語でも英語でも構いません。不具合は、押したキーの順を書いてもらえると助かります）

## 2. Scientific

関数電卓です。ふつうの電卓と同じように、数とキーを打って【=】で計算します。
掛け算と割り算は、足し算と引き算より先に計算します
（【2】【+】【3】【×】【4】【=】は 14）。

### キーの一覧

| キー | 働き |
|---|---|
| 【Shift】 | キーの一部を 2 つ目の働きに切り替える（下の「Shift の面」） |
| 【sin】【cos】【tan】 | 三角関数 |
| 【√】 | 平方根 |
| 【x²】 | 2 乗 |
| 【DRG】 | 角度の単位（DEG / RAD）を切り替える |
| 【ENG】 | いまの答えを工学表記で見る |
| 【ln】 | 自然対数 |
| 【log】 | 常用対数 |
| 【1/x】 | 逆数 |
| 【eˣ】 | 指数関数 |
| 【xʸ】 | べき乗 |
| 【°′″】 | 60 進で打つ・見る |
| 【(】【)】 | 括弧 |
| 【+/−】 | 符号を反転する（指数を打っている途中なら、指数の符号） |
| 【DEL】 | 1 文字消す |
| 【AC】 | 全部消す |
| 【0】〜【9】【000】【.】 | 数字・3 桁のゼロ・小数点 |
| 【+】【−】【×】【÷】 | 足す・引く・掛ける・割る |
| 【=】 | 計算する |
| 【j】 | 虚数単位 |
| 【▸∠】 | 極形式と直交形式を切り替える |
| 【Exp】 | 指数を打つ（【1】【.】【5】【Exp】【3】で 1.5e3、【=】で 1,500） |

### Shift の面

【Shift】を押すと、次のキーが 2 つ目の働きに変わります。

| いつものキー | Shift のあと | 働き |
|---|---|---|
| 【sin】【cos】【tan】 | 【asin】【acos】【atan】 | 逆三角関数 |
| 【eˣ】 | 【e】 | 自然対数の底 |
| 【(】 | 【n!】 | 階乗 |
| 【)】 | 【nPr】 | 順列 |
| 【+/−】 | 【nCr】 | 組合せ |
| 【j】 | 【hist】 | 履歴を開く |
| 【Exp】 | 【π】 | 円周率 |

2 つ目の働きのキーを 1 つ押すと、いつもの面に戻ります。何も押さずに戻すときは、
もう一度【Shift】を押します。

【n!】【nPr】【nCr】は、0 以上の整数でだけ使えます。【nPr】と【nCr】は、
2 つの数の間に置きます（例: 【5】【nCr】【2】【=】）。

### 関数の使い方

関数キーは、数を打ってから押します。いま出ている数に、押したその場で掛かります
（角度の単位が「DEG」のとき、【3】【0】【sin】で 0.5）。

関数は実数の答えを返します。実数の答えが 1 つに決まらない入力（負の数の【√】など）は
「Math ERROR」になります。

【xʸ】は右から計算します。【2】【xʸ】【3】【xʸ】【2】【=】は 2 の 9 乗で 512 です。

【=】のあとに【+】【×】などを押すと、その答えの続きから計算します。

### 表示

- 答えは有効数字 10 桁で出します。整数部には 3 桁ごとにカンマが入ります
- 絶対値が 1e10 以上のときと、0 でなく 1e-9 未満のときは、指数表記になります
  （例: 1e12）
- 打っている途中は、打った文字がそのまま出ます。【=】を押したときに、
  上の決まりで表示し直します
- 表示のために丸めても、中で持っている値は丸めません。表示の切り替え
  （【▸∠】【ENG】【°′″】）は計算をやり直しません

### 角度の単位（【DRG】）

表示の上に「DEG」（度）か「RAD」（ラジアン）が出ます。最初は「DEG」です。
【DRG】で切り替えます。いま出ている数は変わりません。そのあとの三角関数に効きます。
選んだ単位は保存され、次に開いたときも残ります。

### 工学表記（【ENG】）

【ENG】を押すと、いまの答えを、指数が 3 の倍数になる形で見られます
（例: 12345 は 12.345e3）。表示の上に「ENG」が出ます。
【ENG】以外のキーを 1 つ押すと、ふつうの表記に戻ります。

### 複素数と極形式（【j】【▸∠】）

虚数は【j】を使って打ちます。【3】【+】【j】【4】【=】で 3+4j です。
複素数どうしの四則演算ができます。

【▸∠】を押すと、極形式（大きさと角度）で表示します。3+4j は、角度の単位が
「DEG」のとき 5 ∠ 53.13010235 と出ます。表示の上に「∠」が出ます。
もう一度押すと直交形式に戻ります。表示を切り替えるだけなので、中の値は
丸まりません。どちらの形式で表示するかは保存されます。

### 60 進（【°′″】）

【°′″】には 2 つの働きがあります。

- **打っている途中に押すと、区切りになります。** 【1】【°′″】【3】【0】で 1°30、
  【=】で 1.5 です
- **答えが出ているときに押すと、その値を 60 進で見られます。** 3.75 なら
  3°45'0" と出ます。もう一度【°′″】を押すか、ほかのキーを押すと元に戻ります

角度（度・分・秒）にも、時間（時・分・秒）にも使えます。24 で割ることは
しません（30.5 は 30°30'0" と出ます）。60 進で表せない値（1e10 以上など）では、
表示は変わりません。度・分・秒で打った角度は、そのまま【sin】などに渡せます。

### エラー

0 で割ったときや、関数に使えない数を渡したときは「Math ERROR」と出ます。
このときは【AC】だけが効きます。

### 履歴

![画面: 履歴（2 つ計算したあと）](shot:scientific-history)

【=】で答えが出た計算は、式・答え・そのときの角度の単位と一緒に残ります。

- **開く**: 【Shift】→【hist】。電卓の画面に戻るのは【< 戻る】です
- **並び**: 新しいものが上です。50 件を超えると、古いものから消えます
- **答えを使う**: 行を押すと、その答えが入力に入ります。入るのは答えだけで、
  式は入りません。打ちかけていたものは消えます
- **押せない行**: エラーで終わった計算（色が付きます）と、答えをキーで打ち直せない
  計算（虚数・極形式・60 進の答えと、桁数が多すぎる答え）は、一覧に出ますが押せません
- **重ならない**: 直前と式・答え・角度の単位がすべて同じ計算は、1 件にまとめます。
  【=】を続けて押しても増えません
- **続きの計算**: 答えの続きから計算したときは、式の頭に前の答えが付きます
- **1 件消す**: 行の右の【×】
- **全部消す**: 一覧の下の【すべて消す】
- **記録を止める**: 【今後の計算を記録する】のチェックを外します。最初は記録します。
  止めても、記録済みの履歴は消えません
- 【AC】では履歴は消えません。履歴があるのは Scientific だけです

## 3. Convert

単位を換算します。タブのすぐ下の欄で、カテゴリを選びます。

【長さ Length】【質量 Mass】【温度 Temperature】【面積 Area】【体積 Volume】
【速さ Speed】【データ量 Data Size】【為替 Currency】

### 使い方

数字キーの上に、【値】【変換元】【変換先】【⇅】があります。

- **【値】**: 数字キーが出ます。【±】で符号を変えます。【(】【)】と四則演算で式を
  打てます。【=】を押すと、式がその値にまとまります
- **【変換元】【変換先】**: そのカテゴリの単位のキーが出ます。押した単位が選ばれます
- **【⇅】**: 変換元と変換先を入れ替えます。値はそのまま残ります
- **【AC】**: 【値】を選んでいるときは値を消します。【変換元】【変換先】を
  選んでいるときは、その単位を最初の単位に戻します

値を打つと、答えがすぐに出ます。キーの下には、両辺を並べた 1 行
（例: -40 °C = -40 °F）が出ます。

カテゴリを変えると、値と単位は最初に戻ります。値も単位も保存しません。

### 最初の単位

| カテゴリ | 変換元 → 変換先 |
|---|---|
| 長さ | 【km】→【mi】 |
| 質量 | 【kg】→【lb】 |
| 温度 | 【°C】→【°F】 |
| 面積 | 【坪】→【m²】 |
| 体積 | 【L】→【gal(US)】 |
| 速さ | 【km/h】→【mph】 |
| データ量 | 【GB】→【GiB】 |
| 為替 | 【USD】→【JPY】 |

基準が 1 つに決まらない単位は、名前に基準を書いてあります（【畳(1.62m²)】
【カップ(200mL)】【gal(US)】【gal(Imp)】など）。データ量は、10 進の単位
（【kB】【MB】【GB】など）と 2 進の単位（【KiB】【MiB】【GiB】など）を分けています。

### 為替

次の 16 通貨を換算できます。

【JPY】【KRW】【VND】【USD】【EUR】【GBP】【CHF】【CNY】【THB】【SGD】【HKD】【TWD】
【AUD】【CAD】【INR】【BRL】

**レートの取得元**: ExchangeRate-API（https://www.exchangerate-api.com ）の
レート表を使います。画面には「Rates By Exchange Rate API」というリンクが
出ています。レートは取得元の値をそのまま使います。

**取りに行くとき**: 為替のカテゴリを開いたときだけです。アプリを開いただけでは
取りに行きません。ほかのカテゴリを使っているあいだも取りに行きません。
取りに行くのはレート表だけで、入力した金額は送りません。

**保存したレート**: 取ってきたレート表は、この端末に 1 枚だけ保存します。
為替を開くと、まず保存したレートで換算します。保存したレートを取ってから
24 時間を過ぎていると、裏で新しいレートを取りに行きます。取りに行くのは、
ページを開くたびに多くとも 1 回です。

**レートの日付**: 「Rate: 2026-09-10」のように、使っているレート表の日付が
いつも出ます（日付は協定世界時です）。保存したレートが無いときは「Rate: —」です。

**取れなかったとき**:

- 保存したレートがあれば、そのまま換算を続けます。何も知らせは出ません
- 端末がオフラインのときは「Offline」と出ます
- 保存したレートも無いときは「為替レートがありません。インターネットに接続して
  取得してください。」と出て、答えは出ません
- レート表に無い通貨のキーは押せません

**答えの桁**: 答えは、変換先の通貨の桁で丸めます。【JPY】【KRW】【VND】は整数、
ほかの通貨は小数第 2 位までです。【=】は打った値を丸めません。

## 4. Scale

データ量の見積もりです。タブのすぐ下の欄で、【データ量 Data Scale】
【LLM のメモリ LLM Memory】【データ転送 Data Transfer】から選びます。

3 つとも、打てるのは整数です。【(】【)】【÷】【×】【−】【+】【=】は表示されて
いますが、この 3 つの画面では使いません。

### データ量 Data Scale

件数 × 次元数 × データ型から、必要なメモリ量を出します。

- **【件数】**: 数字を打ちます。数の後ろに【K】（千）【M】（百万）【G】（十億）を
  付けられます（【3】【M】で 300 万）
- **【次元数】**: 候補（【384】【512】【768】【1024】【1536】【2048】【3072】【4096】）から
  選びます。候補に無い数は【手入力】で打ちます。【選択】で候補に戻ります
- **【データ型】**: 【int8】【uint8】【int16】【float16】【bfloat16】【int32】
  【float32】【int64】【float64】から選びます。最初は【float32】です。
  【AC】を押すと【float32】に戻ります

件数と次元数の両方を入れると、答えが出ます。キーの下に、バイト数と、10 進の単位
（KB・MB・GB など）、2 進の単位（KiB・MiB・GiB など）での量が出ます。

【10 進 (KB) を主に】と【2 進 (KiB) を主に】で、大きく出すほうを選びます。
この選択とデータ型は保存されます。【LLM のメモリ LLM Memory】と
【データ転送 Data Transfer】も、ここで選んだ単位系で大きく出します。

### LLM のメモリ LLM Memory

LLM の重みと KV cache のメモリ量を出します。項目は 7 つです。

| 項目 | 最初の値 | 選べる候補 |
|---|---|---|
| 【パラメータ数】 | 7B | 【1B】【3B】【7B】【8B】【14B】【27B】【32B】【70B】 |
| 【重みの精度】 | FP16 | 【FP32】【FP16】【BF16】【INT8】【INT4】 |
| 【層数】 | （空） | 候補は無く、数字で打つ |
| 【KVヘッド数】 | 8 | 【1】【2】【4】【8】【16】【32】 |
| 【ヘッド次元】 | 128 | 【64】【80】【96】【128】【256】 |
| 【文脈長】 | 4K | 【2K】【4K】【8K】【16K】【32K】【128K】【1M】 |
| 【KVの精度】 | FP16 | 【FP16】【BF16】【FP32】【INT8】 |

- 【層数】を入れると答えが出ます（ほかの項目には最初から値が入っています）
- パラメータ数の「B」は 10 億です。文脈長の「K」は 1024、「M」は 1024 × 1024 です
- 候補に無い値は【手入力】で打ちます。【手入力】に切り替えると、その項目は空に
  なります。【選択】で候補に戻ります
- パラメータ数を手入力するときは、数の後ろに【B】（十億）【M】（百万）を付けられます
- 【AC】を押すと、精度の項目は FP16 に、数の項目は空に戻ります

答えは「重み」「KV cache」「合計」の 3 行で、それぞれバイト数と 10 進・2 進の
量が出ます。画面の下に、次の説明がいつも出ています。

> 表示しているのは理論値です。
> 実際に必要なメモリはこれより大きくなります。
> 一時バッファ・実行時のオーバーヘッド・量子化のメタデータが加わります。

入れた値は保存しません。

### データ転送 Data Transfer

帯域幅と時間から、転送できるデータ量を出します。

- 【帯域幅】と【時間】に数を打ちます
- 【帯域幅の単位】は【bps】【kbps】【Mbps】【Gbps】から、【時間の単位】は
  【秒】【分】【時】【日】から選びます。最初は【Mbps】と【時】です
- 帯域幅と時間の両方を入れると、答えが出ます

入れた値は保存しません。

## 5. Finance

ローンと複利の計算です。

- **上の段**: 何を求めるか（計算の種類）を選びます
- **下の段**: 入れる項目を選びます。計算の種類によって並びが変わります
- **答え**: 表示の大きな数です。キーの下に内訳が出ます
- **いちばん下**: 計算のしかたの説明がいつも出ています

必要な項目がそろうと、答えがすぐに出ます。

### 数の打ち方

- 金額には【万】【億】を付けて打てます（【3】【0】【0】【0】【万】で 3,000 万円、
  【1】【億】【2】【0】【0】【0】【万】で 1 億 2,000 万円）
- 【年利】は年あたりのパーセントで打ちます。小数点が使えるのは【年利】だけです
- 金額・年利・期間の項目には、四則演算と括弧で式を打てます。【=】を押すと、式が
  その値にまとまります
- 【期間】に入れられるのは 1,200 までです。それを超えるとエラーになります

### ローン（元利均等）

| 計算の種類 | 入れる項目 | 答え |
|---|---|---|
| 【返済月額】 | 【借入額】【年利】【期間】（【残価】か【賞与】も使える） | 月々の返済額 |
| 【借入可能額】 | 【月額】【年利】【期間】（【賞与】も使える） | 借りられる額 |
| 【返済期間】 | 【借入額】【年利】【月額】 | 返済にかかる月数 |

- **【期間】** はか月で入れます。【年】を付けると年で打てます（【3】【5】【年】で 420 か月）
- **【残価】** は【返済月額】でだけ使えます。最後の回に残価を払う形で月額を出します
- **【賞与】** は【返済期間】では使えません。入力済みの欄の見出しは、【返済月額】では
  【ボーナス返済分（元本）】、【借入可能額】では【ボーナス回の返済額】です
- 【返済月額】では、【残価】と【賞与】はどちらか一方だけ使えます

内訳には「総支払額」「総利息」と、使ったときは「最終回（残価）」
「ボーナス回の返済額」「うち月払い分」「うちボーナス分」が出ます。

例: 【返済月額】で、借入額 3,000 万円・年利 1.5%・期間 35 年のとき、答えは
91,855 円、総支払額 38,579,007 円、総利息 8,579,007 円です。

【返済期間】は 1,200 か月（100 年）までしか求められません。それより長くなるときは
エラーになります。

画面の下の説明:

> 実際の返済額は金融機関の計算方法により異なります。

### 複利

| 計算の種類 | 入れる項目 | 答え |
|---|---|---|
| 【複利残高】 | 【元本】か【積立】（両方でもよい）、【年利】【期間】 | 最後の残高 |
| 【必要積立額】 | 【目標】【年利】【期間】（【元本】も使える） | 目標に届く最小の積立額 |
| 【必要年数】 | 【目標】【年利】と、【元本】か【積立】 | 目標に最初に届く期 |

- **【元本】** は最初に預ける額、**【積立】** は毎期の積立額です
- **【期間】** は「期」の数です。1 期の長さは【方式】で選んだ周期で決まります
  （月ごとなら 1 期は 1 か月）。【年】を付けると年で打てます（月ごとなら
  【1】【0】【年】で 120 期）
- 周期が月ごとのときは、【月】も付けられます（1 か月が 1 期です。【1】【年】【6】【月】で
  18 期）。半年ごと・年ごとのときは【年】だけです
- 【月】を付けて期間を打ったあとで周期を月ごとから変えると、期間は空に戻ります。
  打った【月】が、新しい周期では 1 期にならないためです。【年】で打った期間は残ります
- **【必要年数】** の答えは「19 期」のように期の数で出ます。年数にするには、
  周期で割ってください（月ごとなら 12 で割る）
- 1 期あたりの利率は、年利を 1 年の期数で割ったものです

内訳には「元本合計」「運用収益」が出ます。税を引くときは、さらに「国税」「地方税」
「税引前」が出ます。

- 【複利残高】で税を引くときは、大きな数が手取りになります
- 【必要積立額】【必要年数】では、内訳の先頭に最後の「残高」が出ます。税を引く
  ときは、そこが「手取り」になります

例: 【複利残高】で、元本 100 万円・年利 1%・半年ごと・10 期（5 年）のとき、
答えは 1,051,136 円です。

### 方式（周期と積立の位置）

![画面: 複利残高で【方式】を押したところ](shot:finance-method)

【方式】を押すと、次のキーが出ます。

- **周期**: 【月】【半年】【年】。利息を付ける間隔です
- **積立の位置**: 【期末】【期首】
  - 【期末】: その期の利息を付けてから積み立てます。その期に入れた積立は、
    その期の利息を生みません
  - 【期首】: その期に入れた積立にも、その期の利息が付きます
  - 積立が 0（一括で預けるだけ）なら、どちらを選んでも答えは同じです

入力済みの欄には「方式 月ごと・期末」のように出ます。最初は月ごと・期末です。
選んだものは保存されます。

### 税

【税】を押すと【なし】と【20.315%】が出ます。【20.315%】を選ぶと、源泉分離課税を
引いた手取りを出します。最初は【なし】です。選んだものは保存されます。

### 計算の決まり

複利の画面の下には、次の説明がいつも出ています。

> 各期の利息を 1 円未満切り捨て、積立は選んだ位置（期末／期首）に行います。税は国税と地方税を別々に切り捨てます。

- **利息**: 各期の利息は、1 円未満を切り捨ててから残高に入れます。ローンも、各月の
  利息を 1 円未満切り捨てて計算します
- **税**: 20.315% は、国税 15.315% と地方税 5% に分けて、それぞれ 1 円未満を
  切り捨てます。税がかかるのは利息だけで、元本にはかかりません
- **手取りは、期が進むと減ることがあります。** 税の切り捨てのためです。
  そのため【必要年数】は「目標に最初に届いた期」を答えにします。次の期に
  目標を下回ることがありますが、不具合ではありません。
  例: 元本 999 円・年利 1.5%・月ごと・積立なし・税 20.315% で、目標 1,016 円の
  必要年数は 19 期です。20 期の手取りは 1,015 円で、目標を下回ります

答えは決まった手順で出す概算です。金融機関の実際の金額と一致することは
目標にしていません。

## 6. 保存されるものと消し方

CalcArc は、次の 3 つをこの端末のブラウザの中に保存します。外へは送りません。

### 設定

- **中身**: Scientific の角度の単位と表示形式、データ量のデータ型と主に表示する
  単位系、Finance の計算の種類・方式・税、履歴を記録するかどうか
- **消し方**: アプリの中に、まとめて消す操作はありません

### 履歴

- **中身**: Scientific で【=】を押して答えが出た計算。50 件まで
- **消し方**: 【Shift】→【hist】の画面で、1 件ずつなら【×】、まとめてなら
  【すべて消す】

### 為替レート

- **中身**: 最後に取ってきたレート表 1 枚
- **消し方**: アプリの中に消す操作はありません。新しいレートが取れると置き換わります

### 保存について

- 打ちかけの式、項目に入れた数、Convert の単位は保存しません
- **保存した設定と履歴は、版が変わると失われうるものです。** 残ることは
  約束していません
- ブラウザの設定で保存が使えないときは、何も保存しません。知らせは出ませんが、
  計算はそのまま使えます
- ブラウザの設定でこのサイトのデータを消すと、3 つとも消えます
- 保存はこの端末のこのブラウザの中だけです。ほかの端末やブラウザには引き継がれません

## 7. オフラインとインストール、更新の知らせ

### ホーム画面に追加する

ブラウザの機能で、CalcArc をホーム画面に追加できます。追加したアイコンから開くと、
ブラウザの枠の無いアプリの画面で開き、【Scientific】から始まります。

### オフライン

一度開いたあとは、ネットワークが無くても使えるように作っています。為替レートの
取得だけはネットワークが要ります（3 章）。

ネットワークが無いときに動くことを確かめているのは、Chrome 系のブラウザだけです。
iPhone の Safari では、まだ確かめていません。

### 画面の幅

画面の崩れを確かめている幅は、Android の Chrome などが幅 360px 以上、iPhone の Safari が
幅 375px 以上です。それより狭い画面（320px など）でも表示はされますが、崩れないことは
確かめていません。

### 画面の高さ

画面が低いと（ブラウザのタブで開いたときなど）、ページがスクロールすることがあります。
そのときも、すべての表示とキーは、スクロールすれば見えて押せます。1 画面に収まるように
確かめているのは、ホーム画面から開いたときの高さです。

### 更新の知らせ

新しい版が出ていると、画面に次のお知らせが出ます。

> 新しいバージョンがあります。再読み込みすると入力中の内容は消えます。

- 【再読み込み】: 新しい版に切り替えて、ページを読み込み直します。
  打ちかけの入力は消えます
- 【閉じる】（またはキーボードの Escape キー）: お知らせを閉じます。
  この場合は、CalcArc を開いているタブやウィンドウをすべて閉じ、もう一度
  開いたときに新しい版になります

## 8. キーボードからの入力

**キーボードで打てるのは、いまは Scientific だけです。** 【Convert】【Scale】
【Finance】では、キーボードで数字や記号を打っても入力されません。画面のキーを
押してください。

Scientific では、次のキーが使えます。

| キーボード | 画面のキー |
|---|---|
| 0〜9 | 【0】〜【9】 |
| . | 【.】 |
| + | 【+】 |
| - | 【−】 |
| * | 【×】 |
| / | 【÷】 |
| = または Enter | 【=】 |
| Backspace | 【DEL】 |
| Escape | 【AC】 |
| ( と ) | 【(】【)】 |
| j | 【j】 |

- ここに無い働き（【sin】【Shift】など）は、画面のキーを押してください
- Ctrl・Command・Alt を押しながらのキーは、ブラウザの操作に使われます
- 画面のキーを選んでいる（フォーカスがある）ときの Enter は、【=】ではなく、
  選んでいるそのキーを押します
- 更新のお知らせが出ているときの Escape は、【AC】ではなく、お知らせを閉じます

## 9. 読み上げ

画面読み上げを使うときのために、次のようにしています。

- **画面の名前**: 画面ごとに名前があり、読み上げでは見出しとして読まれます。
  ブラウザのタブにも「関数電卓 | CalcArc」のように出ます。名前は次の 13 個です
  - 「関数電卓」
  - 「長さの換算」「質量の換算」「温度の換算」「面積の換算」「体積の換算」
    「速さの換算」「データ量の換算」「為替の換算」
  - 「データ量の規模」「LLM のメモリ」「データ転送」
  - 「金融計算」
- **切り替えの知らせ**: 画面を切り替えると「金融計算に切り替えました」のように
  知らせます。開いた直後は知らせません。読み上げ中の発話に割り込みません
- **答え**: 答えが変わると読み上げます
- **Scientific の状態**: 角度の単位（DEG / RAD）と工学表記（ENG）が変わると
  読み上げます
- **キーの名前**: 記号のキーにも読み上げ用の名前があります（【÷】は「割る」、
  【▸∠】は「極形式と直交形式を切り替え」など）。【Shift】や項目のキーのように
  選んだ状態を持つキーは、押されているかどうかも伝えます
- **押せないキー**: その画面では使わないキーは「この電卓では使えません」と
  説明します
- **履歴の画面**: 「履歴」という見出しが、画面の名前の下に入ります
- **更新の知らせ**: 読み上げでも知らせます

## 10. 困ったとき

### 「計算エンジンを読み込めませんでした。」と出る

「計算エンジンを読み込めませんでした。ページを再読み込みしてください。」と出たら、
ページを再読み込みしてください。

### 「Math ERROR」と出る

Scientific では【AC】を押してから打ち直してください。ほかのタブでは、【DEL】や
【AC】で項目を直してください。

### 答えが出ない

必要な項目がそろっていないかもしれません。Finance は 5 章の表、Scale は 4 章を
見てください。LLM のメモリは【層数】を入れると答えが出ます。

### 押せないキーがある

項目や計算の種類を変えると押せるようになるキーと、その画面では使わないキーが
あります。

### 「為替レートがありません。」と出る

「為替レートがありません。インターネットに接続して取得してください。」と出たら、
インターネットにつないでから、ページを再読み込みしてください。レートを取りに
行くのは、ページを開くたびに多くとも 1 回です。

### レートの日付が古い

保存したレートを取ってから 24 時間を過ぎていれば、為替を開いたときに新しい
レートを取りに行きます。取れなかったときは、保存したレートのまま換算します。

### キーボードで打てない

キーボードで打てるのは Scientific だけです（8 章）。

### 履歴に残らない

【Shift】→【hist】の画面で、【今後の計算を記録する】にチェックが入っているか
見てください。直前と同じ計算は 1 件にまとめます。

### 設定や履歴が消えた

保存した設定と履歴は、版が変わると失われうるものです（6 章）。

https://github.com/terapyon/CalcArc/issues で教えてください。押したキーの順を
書いてもらえると助かります。
