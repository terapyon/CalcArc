最新の PDF（画面写真つき）は、**CalcArc の画面からも開けます**——下部の
「CalcArc <版数> について」を押して【マニュアル】を選んでください。
GitHub の Releases にも添付されています: https://github.com/terapyon/CalcArc/releases

## 1. CalcArc とは

CalcArc は、ブラウザで動く計算ツールです。関数電卓、単位の換算、
データ量の見積もり、ローンと複利の計算ができます。

- 開く場所は https://calc.terapyon.net/ です
- インストールは要りません。ブラウザで開けば使えます
- ホーム画面に追加すると、アプリのように開けます
- 一度開いたあとは、ネットワークが無くても使えるように作っています
  （為替レートの取得だけはネットワークが要ります）。ネットワークが無いときに動くことを
  確かめているのは Chrome 系のブラウザだけで、iPhone の Safari ではまだ確かめていません
- 画面の崩れを自動で確かめている幅は、Chromium 系のブラウザ（Android の Chrome など）が
  幅 360px 以上、WebKit（iPhone の Safari と同じ描画エンジン）が幅 375px 以上です。実機の
  iPhone では確かめていません。320px の画面でも表示はされますが、そこで確かめているのは、
  いちばん下の帯（免責の 1 行）が横にはみ出さないことだけです
- 画面が低いと（ブラウザのタブで開いたときなど）、ページがスクロールすることがあります。
  そのときも、すべての表示とキーは、スクロールすれば見えて押せます。1 画面に収まるように
  自動で確かめているのは、ホーム画面から開いたときの高さで、タブとカテゴリの組み合わせ
  13 のうち 11 について、Chromium と WebKit の両方のエンジンで見ています（【LLM のメモリ
  LLM Memory】と【為替 Currency】の画面は、この検査に入っていません）。これも実機の
  iPhone では確かめていません

## 2. 4 つのタブ

画面のいちばん上に 4 つのタブがあります。押すと画面が切り替わります。

| タブ | できること |
|---|---|
| 【Scientific】 | 関数電卓 |
| 【Convert】 | 単位の換算（長さ・質量・温度・面積・体積・速さ・データ量・為替） |
| 【Scale】 | データ量・LLM のメモリ・データ転送の見積もり |
| 【Finance】 | ローンと複利の計算 |

【Convert】と【Scale】では、タブのすぐ下の欄で計算の種類を選びます
（例: 【為替 Currency】）。

タブと、【Convert】【Scale】で選んだ計算の種類は URL に出るので、その画面は
ブックマークできます。**【Finance】で選ぶ 6 つの計算の種類と、履歴の画面は
URL に出ません。**

## 3. 基本の使い方

### Scientific

ふつうの電卓と同じように使えます。

1. 数字と【+】【−】【×】【÷】を押します
2. 【=】で計算します
3. 打ち間違えたら【DEL】で 1 文字消します。【AC】で全部消します

- 掛け算と割り算は、足し算と引き算より先に計算します
  （【2】【+】【3】【×】【4】【=】は 14）
- 【sin】や【√】などの関数は、いま出ている数に、押したその場で掛かります
  （角度の単位が「DEG」のとき、【3】【0】【sin】で 0.5）
- 答えが出せないときは「Math ERROR」と出ます。このときは【AC】だけが効きます

### Convert・Scale・Finance

この 3 つのタブでは、項目を選んでから数を入れます。

1. 数字キーの上にあるキーで、入れる項目を選びます（例: Finance の【借入額】）
2. 数字を打ちます
3. 必要な項目がそろうと、答えがすぐに出ます

- 【DEL】は、いま選んでいる項目の 1 文字を消します
- 【AC】は、いま選んでいる項目だけを最初の状態に戻します。ほかの項目は残ります
- 入れ終わった項目は、答えの上に小さく残ります
- Convert と Finance では、項目に式を打てます。【=】を押すと、式がその値にまとまります
- **Convert の【値】は【=】で丸めません。** 割り切れないときは `1/3` のように分数の
  まま値になり、続けて打つ計算もその値のまま入ります（例: `1/3*3-1` の【=】は `0`）。
  **答えのあとに数字を打つと、新しい値として打ち始めます**（演算子なら答えの続きです）
- いまは押せないキーは、押せない見た目になっています。項目や計算の種類を変えると
  押せるようになるものと、その画面では使わないものがあります

## 4. 各タブでできること

### Scientific — 関数電卓

四則演算と括弧に加えて、【sin】【cos】【tan】、【ln】【log】、【√】【x²】【xʸ】
【1/x】【eˣ】が使えます。【Shift】を押すと、キーの一部が 2 つ目の働き
（【asin】【acos】【atan】【n!】【nPr】【nCr】など）に変わります。

複素数（【j】）、極形式への切り替え（【▸∠】）、60 進（【°′″】）、
工学表記（【ENG】）、角度の単位の切り替え（【DRG】）もあります。

【=】を押した計算は履歴に残り、【Shift】→【hist】で見返せます。「Math ERROR」で
終わった計算も残ります。

**入力の決まり（要約）**: 手元の値を黙って捨ててしまう打ち方（打ちかけの数の
あとの【(】【π】【e】など）は、そもそも押せません。【DEL】は打ち消しではなく、
演算子は消しません（閉じた【)】は取り消せます）。【=】は閉じ忘れた【(】を
補います。**開いている【(】が無いときの【)】は押せません**。演算子を押し間違えて
すぐ押し直せば、最初から正しく打ったのと同じ答えになります。詳しくは詳細
マニュアルの「入力の決まり」。

### Convert — 単位の換算

【値】に数を打ち、【変換元】と【変換先】で単位を選びます。【⇅】で変換元と
変換先を入れ替えます。長さ・質量・温度・面積・体積・速さ・データ量・為替の
8 つがあります。

為替は、インターネットから取ってきたレートで換算します。為替の【値】にも式が
打て、【=】を押す前から答えが出ます。

### Scale — データ量の見積もり

- 【データ量 Data Scale】: 件数 × 次元数 × データ型から、必要なメモリ量を
  10 進（KB・MB・GB など）と 2 進（KiB・MiB・GiB など）で出します
- 【LLM のメモリ LLM Memory】: パラメータ数や層数などから、LLM の重みと
  KV cache のメモリ量を出します
- 【データ転送 Data Transfer】: 帯域幅と時間から、転送できるデータ量を出します

### Finance — 金融計算

上の段で「何を求めるか」を選び、下の段で入れる項目を選びます。

- ローン（元利均等）: 【返済月額】【借入可能額】【返済期間】
- 複利: 【複利残高】【必要積立額】【必要年数】

金額には【万】【億】を付けて打てます（例: 【3】【0】【0】【0】【万】）。
ローンの期間は【年】を付けると年で打てます（【3】【5】【年】で 420 か月）。

答えは決まった手順で出す概算です。金融機関の実際の金額と一致することは
目標にしていません。

## 5. 保存されるもの

CalcArc は、次のものをこの端末のブラウザの中に保存します。外へは送りません。

- **設定**: Scientific の角度の単位と表示形式、データ量のデータ型と
  主に表示する単位系、Finance の計算の種類・方式・税、履歴を記録するかどうか
- **履歴**: Scientific で【=】を押した計算（新しいものから 50 件まで）。
  「Math ERROR」で終わった計算も残ります（その行は押せません）
- **為替レート**: 最後に取ってきたレート表 1 枚

打ちかけの式や、項目に入れた数は保存しません。

**保存した設定と履歴は、版が変わると失われうるものです。** 残ることは
約束していません。

履歴は、【Shift】→【hist】の画面で消せます。1 件ずつなら【×】、まとめてなら
【すべて消す】です。【今後の計算を記録する】のチェックを外すと、それからあとは
記録しません（記録済みの履歴は消えません）。【AC】では履歴は消えません。

## 6. 無保証であること・入力をサーバへ送らないこと

> **計算結果は無保証です。重要な判断の根拠にしないでください。**
>
> このツールは Apache License 2.0 で提供され、同ライセンスの定めるとおり、
> 明示・黙示を問わずいかなる保証も伴わない。

画面のいちばん下にも「計算結果は無保証です。」と出ています。Finance の画面には、
計算のしかたの説明がいつも出ています。

> 計算は端末内で完結し、サーバへ送信しない。
