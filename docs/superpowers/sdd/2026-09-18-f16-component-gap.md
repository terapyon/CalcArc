**コアの直しは calcarc-ba、検査側（0.9.4 の検査がなぜ通したか・何を足したか）は重量級担当。**
F7（0.9.4）の台帳は [2026-09-18-f7-complex-division.md](2026-09-18-f7-complex-division.md)。

## 1. 何が壊れていたか

0.9.4 の `checked_div` は、分子の 2 成分に**同じ倍率**を掛けて寄せていた
（大きい方の成分の指数から決める）。小さい成分は `2^(−g)` まで寄せられ（g は成分間の 2 進指数差）、
非正規化域を突き抜ける。

| 入力列（キー） | 期待 | v0.9.3 | v0.9.4 |
|---|---|---|---|
| `( 1e308 + 1e-20 j ) ÷ 1 − 1e308 =` | `1e-20j` | 一致 | **"0"、エラー無し** |
| `( 1e200 + 1e-200 j ) ÷ 1 − 1e200 =` | `1e-200j` | 一致 | **"0"** |
| `( 1e308 + 1 j ) ÷ 1 − 1e308 =`（対照） | `1j` | 一致 | 一致 |
| 1 行目に続けて `× 1e20 =` | `1j` | 一致 | **"0"** |

報告と同じ 128 例（指数対 4 × 実虚の入替え 2 × 符号 4 × 除数 {1, −1, 2, j}）では、
**0.9.4 は 96 例が食い違い、96 例すべてで非ゼロの成分が 0 になった**。0.9.3 は 0 例だった。
期待値は代数で決めた（Smith 法も mpmath も通していない）。

### 境目は入力の仮数で動く（**数は仮数と対にして書く**）

÷1 で g を振った。大きい成分は `2^e`（e = 1023・700・100 のどれでも同じ）。

| 小さい成分の仮数 | 精度を失い始める g | 0 になる g | 測った人 |
|---|---|---|---|
| 1.0（2 の冪） | — | 1075 | calcarc-ba・calcarc-1e |
| 1.5（仮数 2 ビット） | 1074 | 1076 | 重量級担当・calcarc-1e |
| 4/3（仮数が満ちる） | **1023** | 1076 | 重量級担当・calcarc-1e |

**「0 になるのは 1075 か 1076 か」は、一時 2 人の報告で食い違った。** 定義の違いではなく、
**入力の仮数の違いだった**（calcarc-1e が 0.9.4 本体で掃引して決着）。
**2 や 10 の冪は精度の帯（1023〜1074）を隠す**——下の §3 の「仮数を満たした値」はこのためである。

大きい成分が `2^0` 以下なら壊れない（倍率が上向きになるため）。

## 2. 0.9.4 の検査がなぜ通したか（外部の見立て 3 点を実測で当て直した）

| 見立て | 判定 | 根拠（2026-09-18 実測） |
|---|---|---|
| ① 生成器の成分比が 1:1・8:1・1:8 だけで、成分間の指数差が軸になっていない | **真** | 分子の両成分が非ゼロの 304 行で指数差は**最大 3**、分母の 342 行も最大 3、期待値の 48 行で最大 12。F16 は 1023 以上で起きる |
| ② 分子と分母が z/z などで結び付いていて、尺度を独立に振っていない | **真** | 有限の 560 行は**すべて恒等式**。F16 の値で `z/z`・`z/(2z)`・`z/(z÷2)` を 7 行足すと、**7 行とも厳密一致で緑**——分子と分母で同じ成分が同じように消え、答えが実数に戻る。**結合形は F16 を仕組みの上で見ない** |
| ③ 比較器が大きい方の期待成分で両成分の差を割る | **真** | `(1e308, 1e-20) ÷ 1` の差 `1e-20` を `1e308` で割ると f64 で 0。**「許容内」に数えられた** |
| ④ 件数の番人（`EXPECTED_INEXACT = 8`）との関係 | **落ちる。ただし正しい理由ではない** | 独立な 12 行を足すと `left: 20 right: 8` で赤。失敗の文は「件数が 8 と違う」で、**成分が消えたとは言わない**。註に従って 8 → 20 に直せば、所属の assert を除いて緑に戻る形だった |

## 3. 何を足したか

**0.9.4 の 572 行は 1 バイトも変えない。** `reference/tests/test_complex_div_boundary.py` が
572 行の sha256 で見張る（`F7_SHA256`）。足したのは 3 つの族で、全体は 1660 行。

| 族 | 何を振るか | 行数 |
|---|---|---|
| `gap/` | 分子の成分間の指数差 g（0〜2000）× 大きい側の指数（1023・700・1・−500）× 実虚の入替え × 符号（除数 1 のとき）× 除数 {±1, 2, ±j} | 622 |
| `den_gap/` | 分母の成分間の指数差 × 分子の大きさ（分母の大きさ・2^1023・600 下。**分母から切り離す**）× 分子の形。分子と分母の両方が広い行も | 456 |
| `chain/` | 大きい成分を引いて小さい成分を取り出す列と、それを拡大する列（§1 の 4 列と同じ形を値の層で。段ごとに f64 へ丸める） | 10 |

- **仮数は満ちた値**（4/3・12/7・10/9）。`test_the_mantissas_are_full` が値の側で縛る
- **判定は成分ごと**（`crates/calcarc-core/tests/support/complex_div_boundary_body.rs` の `component_failures`）:
  期待が 0 なら厳密に 0／期待が非零なら得た値も**非零で同じ符号**／差は `max(rel·|期待|, abs_floor)` 以内。
  失敗の文は「成分 im が 0 に潰れた（期待 1e-20）」のように**何が起きたかを名指す**
- **非正規化域の許容 `abs_floor` = `rel × 2^-1022`**（f64 で `2.5e-323` に丸まり、**実効は最小の非正規化数のちょうど 5 個分**）。新しい定数ではなく、
  **相対の規則を正規化数の下端から下へ延ばしたもの**。0.9.4 で退けた「`1e-320` の行を丸ごと呑む `abs`」とは
  桁が違う（理由は生成器の `TOLERANCE_ABS_FLOOR` の註）
- **成分ごとの判定が意味を持たない行は置かない**: 2 項が打ち消し合う成分（条件数 > 2）があれば
  生成器が**止まる**（黙って落とさない）。0.9.4 の行には当てない——実際 `e-320` の `double` 族 8 件は、
  虚部が打ち消しで作られる（条件数 505）
- **本文は 1 か所**。native と wasm32 の 2 つのテストが同じファイルを `include!` する
  （0.9.4 までは写しで、「片方だけ直すと違う主張になる」を註で断っていた）
- **件数の番人は、成分の判定を通った行だけを数える**。F7 の 8 件と新しい族の 8 件を分けて、場所も主張する

## 4. 測った結果

**「失敗の数」は失敗の文の数で、成分ごとに 1 つ出る**（1 行で 2 成分が崩れれば 2 と数える）。

| | 失敗の数 | 内訳 |
|---|---|---|
| **de50c40（0.9.4）** | 1660 件中 **226** | gap/ 190（0 に潰れた 94・許容超え 96）、den_gap/ 28、chain/ 8（すべて 0 に潰れた） |
| **v0.9.3** | 1660 件中 **128** | gap/・chain/ は **0**。den_gap/ 28（**0.9.3 から在った Smith の `t` の潰れ**）と F7 の行 |
| **891ac5b（直し）** | **0** | 厳密一致 1626／許容内 F7 8・新しい族 8／範囲外を正しくエラー 18。**den_gap/ の 28 も緑** |

**直しは 0.9.3 から在った穴（den_gap/ の 28）も閉じた。**

新しい族の 8 件は**すべて `den_gap/` で、正規化域の 1 ULP**（成分ごとに bit の差を数えた）。
`gap/` と `chain/` は全件ビット一致（除数が実数か純虚数なので成分が混ざらない）。

**wasm32 も緑**（`wasm-pack test`、2026-09-19）。番人は件数（F7 8・新しい族 8）と場所を assert で言うので、
**緑は native と同じ数・同じ場所であることを意味する**（wasm-bindgen-test は緑のとき印字しない）。

### 直しの上の変異（直したあとの番人が、次の壊し方でも鳴るか）

| 変異（`value.rs`） | 失敗の数 | 捕まえた族 |
|---|---|---|
| 0.9.3 の Smith 法に戻す | 128 | F7 100・den_gap/ 28 |
| 0.9.4 の寄せ方に戻す | 226 | gap/ 190・den_gap/ 28・chain/ 8 |
| 倍率を実部だけから取る（虚部を実部の指数で寄せる） | 250 | gap/ 238・chain/ 8・den_gap/ 4 |
| `to_f64` で非正規化数の結果を 0 に落とす | 140 | gap/ 80・den_gap/ 60（**F7 は 0**——恒等式の答えは非正規化数にならない） |
| 積だけ f64 の範囲に戻す（`Wide::mul`） | 24 | **F7 だけ** |

**最後の行が、F7 の行を残す理由の実例である。** 新しい族は「積が f64 を外れ、そのあとの割り算で戻る」形に届かない。
分母の大きい側が小さく（`2^-500`）、しかも成分間が広い分母は、小さい側が f64 の下に落ちて作れないためである。
