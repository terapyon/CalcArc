## 踏んだ人へ（将来、この文面を見たら）

```
<シャード>/<要求 id>: 試験空間モデル「scientific-v1」が、
データに無いセルを N 件指している: <セルの名前>
  **これはあなたの変更が壊したのではない可能性が高い。**
```

**これは「あなたのコードが壊れた」ではない。** モデルが
**「この組合せの入力がコーパスに 1 件も無い」**と言っている。**やることは 3 つ:**

1. **そのセルが作れるか測る。** 主張ではなく、探針を組んで当てる
   （`reference/tests/test_corpus_science.py` の
   `test_the_holes_we_could_fill_are_actually_reachable` が手本）
2. **作れるなら埋める。** 理由を貼らない——**作れるセルに理由を貼るのは嘘**で、
   `test_a_reachable_hole_is_never_given_a_reason` が落とす
3. **作れないなら理由を貼る。** 理由は**一次資料を名指し**する
   （例: `complex/operation=power` は engine の
   `power_rejects_complex_operands` が「複素の冪は `DomainError`」と固定している）

**止まるのはリリースであって、マージではない。** `heavy-corpus.yml` は
`workflow_dispatch` と `workflow_call` でしか走らず、毎回の CI が回すのは
`heavy` の型検査・lint・vitest だけである（2026-08-30 に現物で確認）。

## 1 度目に何が起きたか

**赤かった期間: 2026-08-30 の Task 5 から Task 14 まで**（同日中に解決）。

**始まり**: 試験空間モデル `scientific-v1` を値シャードの門に掛けたとき、
**本当の穴が 7 件**出た。**そのうち人が知っていたのは `Rad × 逆三角` の
4 件だけ**で、残り 3 件はモデルが先に見つけた。

**終わり方は 1 通りではなかった。** 最終的に 0 件になるまでに、
**穴の数は 7 → 3 → 7 → 3 → 2 → 1 → 0 と動いた**——**増えた 2 回は、
「測れない」と宣言していた軸を測れるようにしたときである。**

| 穴 | どう閉じたか |
|---|---|
| `inverse_trig` の Rad 4 件 | **埋めた**（`angle_toggle` を先頭に押す 3 件） |
| `elementary/band` の負・ゼロ | **埋めた**（`e^0` と `e^-5`。`ln(0)` と `1/0` はエラーなので値シャードに入らない） |
| `asin(1)` / `acos(1)` | **埋めた**（表が名指しする定義域の境目） |
| `complex/zero_part=both_zero` | **埋めた**（`(j5 - j5)`。乱択では 2 つの葉が厳密に等しくならない） |
| `complex/operation=power` | **理由を貼った**（engine が複素の冪を拒む。`not_applicable`） |
| `combinatorics/path=domain` | **新しいシャードを作った**（`combinatorics-display-000.json`） |
| `combinatorics/path=overflow_near` | **穴ではなかった**（§14.2 の「近傍」を「溢れた」に写していた射影の誤り） |
| `display/edge=rounding_carry` | **埋めた**（`9999999999.5`。**それまでの註は「繰り上がる」と書いていたが、繰り上がっていなかった**） |

## この 1 度で分かったこと

- **「測れない」という札は、穴を隠す。** 4 つの軸に貼ってあった理由のうち
  **3 つが実データと食い違っていた**——測れるようにしたら、そこから
  **本当の穴が 5 件**出てきた
- **穴の数が減ることだけを良いとしない。** 減り方には
  **埋めた・理由を貼った・射影を直した**の 3 通りがあり、**最後の 1 つは
  「表を綺麗にする」動きと外形が同じ**である。**だから記録に「赤が 1 つ消えた」と
  明記した**（`OVERFLOW_NEAR_FLOOR` の docstring）
- **赤を置いてよい。** ただし**置いた日に、解ける条件と、踏んだ人への説明を
  書く**。この文書がその形である

**数字の一次資料は [`docs/corpus-measurements.md`](../../corpus-measurements.md) にある。**
