# 0.9.6 実装の台帳

**マニュアルをアプリの中で読む画面**（設計書
`docs/superpowers/specs/2026-09-23-manual-screen-design.md`、1e 承認 2026-09-23）。

## なぜこの版が在るか（**実測 2 件**）

**iPhone のホーム画面アプリでは、PDF を開く道はどの経路でも行き止まりだった。**

| 版 | 手 | 結果（利用者の実機） |
|---|---|---|
| 0.9.4 | サイト内の PDF ＋ `Content-Disposition: attachment` | **窓ごと PDF に変わって戻れない**（ヘッダは本番で付いていた。監視役の `curl`） |
| 0.9.5 | GitHub Release の添付（別の生成元） | **内部のブラウザ表示から戻れない**。利用者の言葉「**PDF が開くが、閉じる・戻るのボタンが見当たらない**」 |

**どちらも「端末が PDF をどう扱うか」に賭けていた。** 0.9.6 は賭けをやめ、
**本文をアプリの中の画面（`#manual`）で読ませる**。**PDF はそこから開く
保存・印刷用の副経路**である。

## 0.9.5 の宿題の取り消し

の該当節に取り消しを書いた）。**アプリがまたそこを指すからである。**

`functions/manual/[[path]].js`（節ごと書き直し）／`.github/workflows/deploy.yml` の
スモークの註／`web/scripts/check-sw.mjs` の 3b／`web/tests/unit/manual-function.test.ts`
（題と註）／`docs/deploy.md` の 2 か所／`2026-09-19-v0.9.5-implementation.md` の宿題の節。
**直さなかったのは `CHANGELOG.md` の 0.9.5 の項**——**出た版の記録は書き換えない。**
**向きが変わったことは 0.9.6 の項に書く**（版上げのコミット）。
