## 枝 1: `test/goto-retry`（E）

**設計書 §5。** WebKit の `page.goto` が内部エラーで落ちたときだけ、**1 回だけ**やり直す。
**判定・しきい値・待ち時間は 1 つも緩めない。**

**番人が塞いでいる道**（`tools/tests/webkit-gate.test.ts`）:
`config.retries` は 0（`:61`）／project は `use`/`name` 以外の鍵を持てない（`:58-59`）／
`fixtures.ts` の `{ auto: true }` は**ちょうど 2 個**（`:465`）。
→ **`retries` を触らず、`{ auto: true }` も増やさない**——**`page` フィクスチャを上書きする。**

### 手順

- [x] 番人に **5 本**の assert を足す（**先に赤くする**。4 条件＋記録）
- [x] `fixtures.ts` で `page.goto` を包む（WebKit かつ原文一致のときだけ、1 回）
- [x] やり直しを `testInfo.annotations` に残す
- [x] 緑を確認（`heavy` の `pnpm test` で番人、`web` の型検査と lint）
- [x] **既存の番人 2 本の赤に対処**（許可一覧と、註の綴り。下の記録）

### 記録（2026-09-17）

**赤くしたもの（実装の前）**: 番人に 5 本足して走らせ、**5 本とも落ちることを原文で確かめた**
——`expected [] to deeply equal [ 'goto' ]`／`expected [] to have a length of 2`／
`to match /browserName !== "webkit"/`／`to match /WebKit encountered an internal error/`／
`to match /annotations\.push/`。**空配列や不一致で落ちている**ので、
**「間違った理由で赤い」ではない。**

**緑にしたもの**: `fixtures.ts` で `page` を上書きし、`goto` だけを包んだ。
→ `webkit-gate.test.ts` **44 本緑**（39 + 5）、`heavy` の `pnpm test` **364 本緑**（359 + 5）。

**★ 途中で、既存の番人 2 本を赤くした。** どちらも**私の変更が本当に踏んだもの**である:

1. **`browserName` に触れる E2E は 3 つだけ**——`fixtures.ts` が 4 つ目になった。
   **許可一覧に理由つきで足した**（「**期待値を分ける分岐ではなく、救う範囲を狭める分岐**である」）。
   **数も `3 つ` → `4 つ` に直した**（題名だけ古い数が残るのを避ける）
2. **`{ auto: true }` はちょうど 2 個**——**3 個に増えていた**。
   **増えた 1 個は私が註に書いた綴りだった**（フィクスチャは増やしていない）。
   **番人は本文を数えるので、註に綴りを書くと数が動く**——**註のほうを書き換えた**。
   **今日 `include_str!` で踏んだのと同じ形**（`grep` は註を区別しない）が、
   **今度は自分が番人を鳴らす側**で出た。`fixtures.ts` の註にその旨を 1 行残した

**門**: `web` の `pnpm typecheck`（`tsc --noEmit`）緑・`pnpm lint` 緑（173 ファイル）、
`heavy` の `pnpm lint`（**`tools/` も見る**）・`pnpm typecheck` 緑。
**`web/src/wasm` は wt-V から写した**（gitignore 済み。**wasm のビルドは重い段なので回していない**）。

**E2E は回していない。** この枝が触るのは**フィクスチャの入口**なので、
**本当の確認は WebKit の走行**（CI）である。**手元で 102 か所の `goto` を全部走らせる価値は薄い**
——**回すなら calcarc-e3 に一言してから**（重い段）。
