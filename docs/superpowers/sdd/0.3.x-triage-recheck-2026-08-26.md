push の rebase で SHA が変わったのに、索引が push 前の SHA を持ち続けていた
（`stacked-branches-need-rebase-after-push` の型）。**索引に SHA を書くなら、push 後に
当て直すか、SHA ではなく件名で指すべきである。**

**A1 は索引より 1.5 倍大きい**（2 パネル → 3 パネル、14 キー → 21 キー）。
