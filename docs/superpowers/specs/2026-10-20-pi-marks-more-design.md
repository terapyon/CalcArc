## §2 形

### §2.1 整数の指数の `xʸ`——**指数の印が整数なら、`×` と `1/x` を重ねたのと同じ印**

**規則**（指数 `y`、底 `x`。どちらも虚部が 0 のとき。値は今までどおり `scientific::pow` が先に計算し、定義域の誤りもそこで出る）:

| 指数の印 | 底の印 | 答えの印 |
|---|---|---|
| 整数 `n`（π を含まない有理数で、分母が 1） | **`n = 0` なら底の印を問わない** | `1`（`0 xʸ 0` も 1。値の `pow` も 1 を返す） |
| 同 | 単項 `qπᵏ`（`q ≠ 0`） | `qⁿ·π^(kn)`。**負の `n` も**（`1/x` と同じく単項だけ） |
| 同 | 0 | `n > 0` なら 0（`n < 0` は値の計算が先に `DomainError`） |
| 同 | 和（項が 2 つ以上） | `n ≥ 1` なら自分との積を `n − 1` 回（`π + 1` の 2 乗は `π² + 2π + 1`）。**`n < 0` は落とす**（`1/x` と同じ）。回数の上限は置かない（下の註） |
| 同 | **root `(c, r, pi)`** | **偶数の `n`**: 単項 `(c²r)^(n/2)·π^(pi·n/2)`（`x²` が root を単項に戻すのと同じ）。**奇数の `n`**: 落とす（`×` が root を落とすのと同じ） |
| 整数でない（`1/2` を除く）・π を含む・root・印なし | — | 落とす（今と同じ）。`1/2` は 1.2.5 の `√` の腕のまま |

- **k が −2〜4 の外へ出る冪、`i128` の溢れは印を落とす**（1.2.5 と同じ。`π xʸ 5`、`2 xʸ 130`）。
- **`qⁿ` は 2 乗を重ねる形で計算する**（`|n|` が大きくても段の数は 128 以下）。どの段で溢れても落とす。
- **和の底の積に回数の上限（試作の `n > 8` で落とす）は要らない**（レビューの注記 3）。和は k の違う項を 2 つ以上持つので、k の幅は 1 以上で、`m` 回掛けると幅は `m + 1` 倍以上になる。幅が 6（−2〜4）を超えた積は範囲の外で落ちるので、**どんな `n` でも 6 回以内の積で終わる**。上限は、この理由を知らない読み手に「8 に意味がある」と思わせるだけである。
- **値は変えない。** 今の `pow`（`powf`）のまま。印が π を含まない有理数なら、`Held::settled` が `re` を印の丸めに置き換える（1.2.2 からの規則。`1.1 xʸ 2 =` の `re` は `1.2100000000000002` から `1.21` になる）。
- **これで綴りがそろう**: `π xʸ 2` と `π x²`、`π xʸ 1 +/−` と `π 1/x`、`π √ xʸ 2` と `π √ x²` が同じ印になる。

### §2.2 逆三角関数——**表に載る引数なら、答えに印を付ける**

**規則**: `asin`・`acos`・`atan` の引数を **`signed_square` で「符号と 2 乗」に読む**（1.2.3 の `cancel` と同じ読み方。π を含まない有理数の印 `q` なら `(q < 0, q²)`、`pi = 0` の root `(c, r, 0)` なら `(c < 0, c²r)`）。2 乗が表に載れば、答えの角を π の有理数倍 `t·π/12` で決める。

| 関数 | 引数の 2 乗 → 答え（引数が正のとき。負なら asin・atan は符号を反転、acos は `π − 答え`） |
|---|---|
| `asin` | 0 → 0、1/4 → π/6、1/2 → π/4、3/4 → π/3、1 → π/2 |
| `acos` | `π/2 − asin` |
| `atan` | 0 → 0、1/3 → π/6、1 → π/4、3 → π/3 |

- **RAD**: 答えの印は単項 `(t/12)·π`（k = 1）。**`re` は今の f64（`asin` の値）のまま**——π を含む印は `re` を丸め直さない（1.2.2 の規則）。
- **DEG**: 答えの印は有理数 `15t`（度）。`Held::settled` が `re` を置き換える（`0.5 asin` の `re` は `30.000000000000004` から `30`。表示は今も `30`）。
- **表に載らない引数・π を含む印・`pi ≠ 0` の root・印なしは落とす**（今と同じ）。
- **複素の経路には入らない。** 逆三角関数の値の計算（`scientific::asin` ほか）は虚部のある引数を `DomainError` で断るので、印の計算に届く前に答えが決まる。印の関数は念のため虚部 0 を確かめる（`tan` の印と同じ書き方）。
- **引数に `√` の印を読むのは、`0.5 √ asin`（π/4）・`3 √ atan`（π/3）・`0.75 √ acos`（π/6）を通すため**。`2 √ ÷ 2 = asin` は root が `÷` で落ちるので通らない（§7.1）。

**数**: 逆三角関数を切ると直る本数は 115 → **45**（70 本がこの族。第 1 版の 69 本に、畳みの直しと両方が要る 1 本が加わった）。root の引数だけを切ると 115 → **108**（7 本）。

**★ 見える変化（U5）: RAD で、逆三角関数の答えが π/2 の奇数倍になる角の `tan` は `Math ERROR` になる。** `0 acos tan`・`1 asin tan`・`1 atan × 2 = tan` は今 `1.633123935e16`、後は `Math ERROR`（`TrigPole`）。
- **今の `numerical-policy.md` は、これを「従来どおり」と明記している**（「`acos(0)` のような関数の答えも π/2 そのものではないので、従来どおり有限の巨大値を返す（`0 acos tan` は `1.633123935e16`）」）。この文は偽になる。
- **DEG では今も `Math ERROR`**（`0 acos` が `90` で、表の極に当たる）。RAD だけが違う今の形のほうが、モードで割れている。
- 1.2.5 の U3（`2 ÷ π = 1/x tan` を `Math ERROR` に）と同じ理屈である。

### §2.3 k = 0 の平方数の √——**`√q` で `q` が有理数の平方なら単項 `√q`**

**規則**: `exact::sqrt` の「0 でない偶数の k で平方数なら単項」から「0 でない」を外す。**`4 √` の印は `2`、`2.25 √` は `3/2`、`0.01 √` は `1/10`**。平方数でない `q` は今までどおり root `(1, q, 0)`。`xʸ 0.5` も同じ（`√` の印を使う）。

### §2.6 RAD の角を「90° 単位とずれ」に分けて畳む——**±π・±π/2 の近くの丸め**（追記 1）

**原因**: `exact::pi_turn`（RAD で印が単項 k = 1 の角 `qπ`）は、`r = q mod 2` を `(−1, 1]` に畳んだ `r` を f64 にしてから `× π` する。
- `r` が ±1 に近い（角が π の奇数倍に近い）と、`sin`・`tan` の答えは `π(1 − |r|)` ほどに小さいのに、f64 の `r` の丸め（絶対で 2⁻⁵³ ≈ 1.1e-16）がそのまま答えの誤差になる。
- **同じことが ±1/2 の近く（角が π/2 の奇数倍に近い）の `cos`・`tan` でも起きる**——`cos` は `π(r ∓ 1/2)` ほどに小さい。
- 0 の近く（と 2π の近く）は起きない——`r` 自身が小さいので、f64 の `r` は相対で正しく丸まる。
- **1.2.4 の DEG（`degree_turn`）は同じ問題を「いちばん近い 90° の倍数とずれに分け、ずれだけを f64 にする」で直した。RAD には同じ直しが入っていなかった。**

**直し方**: `r` を、いちばん近い `k/2`（`k` は整数）と、ずれ `δ = r − k/2`（`[−1/4, 1/4]` の有理数）に分ける。**f64 にするのは `δ` だけ**で、`Turn::Folded { quarter: k mod 4, radians: f64(δ) × π }` を返す。`quarter` の回し方は DEG と同じ（`scientific::circular`）。表に載る角（`12 % d == 0`）は今どおり先に表で返す。`i128` が溢れたら `None`（今と同じく f64 の道へ）。

## §9 Rust の書き方

- **panic しない。** `unwrap`・`expect` を書かない。溢れは全部 `?` で印を落とす。試作の `as` の類いは `try_from` にする。
- **MSRV は 1.88**（1.2.5 で上げた。CI の `Rust MSRV` の段と `msrv-pin.test.ts` が見張る）。let チェーンは使ってよい。
- **pub の面を広げない。**
  - 新しい印の関数（`xʸ` と逆三角関数）は `pub(super)`。
  - **逆三角関数の印は 1 つの関数にする。** 3 つのキーごとに薄い関数を置くと「包むだけの関数」になる。キー（`Key::Asin` など）か小さな列挙を引数に取る形を推す（実行役の判断）。`apply_unary` の `mark: fn(Held)` には角度モードが入らないので、`apply_trig` と同じく専用の遷移を 1 つ置く（試作は腕の中に直接書いた）。
  - 有理数の冪は `expr::rational` に `pub(crate)` で置く（`Rational` は `pub mod expr` の下にあるので、`pub` にするとクレートの外の面が増える）。
- **包むだけの関数を作らない。** `signed_square` を逆三角関数でも使う（`cancel` と読み方が同じ）。
- **註に作業の経緯を書かない。** 「試作で測った」「1.2.5 までは」の類いは、この設計書と台帳に置く。
- **新しい依存を足さない。** 試作のコードを写さない（§0）。
