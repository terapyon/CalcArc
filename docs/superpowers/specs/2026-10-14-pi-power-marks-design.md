## §1 今の外れ方（**e231550 で取り直した**）

台帳 §2 の 5 行は `d43cf71` の実測だった。`e231550` で取り直すと、表示は 5 行とも同じだった。

| 族 | キー列 | 今の表示 | 真値 |
|---|---|---|---|
| k = −1 | RAD `1 ÷ π = 1/x sin` | `1.224646799e-16` | `0` |
| k = 2 | RAD `π × π = ÷ π = sin` | `1.224646799e-16` | `0` |
| k が混ざる和 | RAD `π + 1 = − 1 = sin` | `1.224646799e-16` | `0` |
| √π | RAD `π √ x² sin` | `5.665538898e-16` | `0` |
| x^0.5 | `2 xʸ 0.5 = x² − 2 =` | `4.440892099e-16` | `0` |

**根は 1 つである。** 今の印は「有理数 × π^k（k は 0 か 1）」の**単項**しか持てない。印が落ちる所は 4 つある。
- **k が範囲の外へ出る**: `1 ÷ π`（k = −1）、`π × π` と `π x²`（k = 2）。
- **k の違う 2 つを足す**: `π + 1`。
- **√ の印 `Root` は k = 0 の正の有理数にしか付かない**: `π √` で落ちる。
- **`xʸ` は印を全部落とす**: `2 xʸ 0.5` に印が付かない。

一度落ちると、あとで π が消えても（`÷ π`、`− 1`、`1/x`、`x²`）戻らない。f64 の π で計算した角が三角関数に届く。

### §2.2 A の印——**`Exact` の中身を 4 つの係数にする**

- **`re == q₋₁/π + q₀ + q₁π + q₂π²`**（虚部は問わない。今と同じ）。
- **正規化は要らなくなる。** 今の `(0, k=1)` を `(0, k=0)` に直す規則は、「全部 0」が 1 通りしか無い形に吸収される。
- **`Held::settled` が `re` を丸め直すのは、`q₀` 以外が 0 のときだけ**（今の「k = 0 のときだけ」と同じ意味）。π を含む値は今までどおり f64 の計算のままである。
- **「単項か」を読む関数を 1 つ置く**（`monomial() -> Option<(k, q)>`。全部 0 なら `(0, 0)`）。三角関数・`1/x`・`÷` の割る側・`√` が読む。

### §2.3 `Root` との関係——**`Root` に 1 ビット、`Exact` とは混ぜない**

- **`Root { c, r }` に `pi: bool` を足す。** 意味は `re == c × √(r × π^pi)`（`pi` が true なら √ の中に π が 1 つ入る）。
- **作る道は今の 2 つのまま。**
  - `√`: 引数の印が単項で、`k = 0` かつ `q > 0` なら `(1, q, false)`。ここは今と同じ。
  - **`k = 1` かつ `q > 0` なら `(1, q, true)` を新しく作る。**
  - `x^0.5`: 下の §3.1 の xʸ の行。
- **読む所も今のまま 2 つ。**
  - **`x²`**: `(c, r, pi)` を `c²r × π^pi` にして返す（k = 0 か 1 の単項）。`π √ x²` は `π` の印に戻る。
  - **`cancel`**（√ の和・差の書き換え）: **`pi = true` の root は読まない**（`signed_square` が `None` を返す）。π の √ どうしの差は今と同じ f64 の和に落ちる。1.2.3 の 2 倍の門と書き換えの式は、k = 0 の root だけに効く。
- **`Root` を `Exact` の係数に混ぜない理由**: √ は多項式の外の数である（`√2` も `√π` も、π の有理係数の和では書けない）。
  - 混ぜるなら「√ の中身 × π の多項式」の 2 段の形が要る。
  - そうしても、直る行（§1 の √ の 2 行）は 1 ビットの `pi` で直るものと同じである。
- **範囲外にするもの**: `π x² √`（`√(π²) = π`）と、k = −1 の √（`1 ÷ π = √`）は持たない。§7 の U1。

## §3 どの演算で印を保ち、どこで捨てるか

### §3.1 演算ごとの規則

| キー | 今（e231550） | A |
|---|---|---|
| 打った数・`π`・`0`・表の答え | 単項 k = 0 か 1 | 同じ（係数の 1 つだけが 0 でない） |
| `+`・`−` | k が同じか片方が 0 なら和、違えば落とす | **係数ごとの和**。溢れたら落とす。`cancel` は §2.3 のとおり k = 0 の root だけ |
| `×` | k の和が 1 以下なら積、2 なら落とす | **多項式の積**。積の項が k ∈ {−1, …, 2} の外に出たら落とす。複素なら落とす（今と同じ） |
| `÷` | 割る側が k = 0、または両方 k = 1 | **割る側が単項で 0 でないとき**、割られる側の各係数を割り、k をずらす。範囲の外へ出たら落とす。**`0 ÷ x` は 0**（今と同じ）。割る側が和（`÷ (π + 1)`）なら落とす |
| `+/−` | `(−q, k)`、root は `(−c, r)` | 係数ごとに符号を反転する。root は `(−c, r, pi)` |
| `x²` | k = 0 なら `q²`、root なら `c²r`、k = 1 は落とす | **自分との積**（`π x²` は k = 2、`(π + 1) x²` は `π² + 2π + 1`）。root は `c²r × π^pi` |
| `1/x` | k = 0 で 0 でなければ `1/q` | **単項なら `(1/q, −k)`**。範囲の外（k = −2）なら落とす。和なら落とす |
| `√` | k = 0 の `q > 0` で root `(1, q)`、0 は 0 | 単項で `q > 0` のとき、**k = 0 なら `(1, q, false)`、k = 1 なら `(1, q, true)`**。0 は 0。k = −1・2・和・負は落とす |
| `xʸ` | 落とす | **指数の印がちょうど k = 0 の `1/2` で、底と指数が実数なら、`√` と同じ印**。それ以外は落とす（整数の指数は範囲外。§7） |
| `sin`・`cos`・`tan` | §3.2 | §3.2 |
| `ln`・`log`・`eˣ`・`n!`・`nPr`・`nCr`・逆三角関数 | 落とす | 同じ |

**`xʸ 0.5` の値も `√` で計算する。**
- `x.powf(0.5)` と `x.sqrt()` は、打った 20,000 個の十進のうち 13 個で 1 ビット違った（この作業機のネイティブ）。√ は正しく丸めるが、`powf` はそうとは限らない。
- root を持つ値の `re` は「√ の f64」である（`Held::settled` の註、1.2.3 §3.1）。`powf` の値のまま印だけ付けると、この不変が x^0.5 で嘘になる。
- 計算を √ にそろえても、コーパスと乱択の表示は 1 件も動かなかった。コーパスは生の値も動かない（`xʸ 0.5` が 0 本）。
- **定義域の誤り（負の底）は、今の `scientific::pow` を先に呼んで出す**（1.2.3 の `apply_log` と同じ順）。

### §3.2 三角関数——**角を決める規則は増やさない**

| 角度 | 引数の印 | 角の正体 |
|---|---|---|
| RAD | **単項 k = 1**（`qπ`） | `pi_turn(q)`。表か、`(−1, 1]` に畳んだ角（今と同じ関数） |
| RAD | ちょうど 0 | 表の 0（今と同じ） |
| RAD | それ以外（k = −1・2・和・0 でない k = 0） | 表を引かない。f64 の値の `sin`・`cos`（今と同じ。`turn_of` は RAD で表を引かない） |
| DEG | **単項 k = 0** | `degree_turn(q)`（1.2.4 の規則） |
| DEG | それ以外 | f64 の規則（`turn_of`。今と同じ） |

**変わるのは「単項 k = 1」「単項 k = 0」に届く道が増えることだけ**で、角を決める関数は 1 行も変えない。
- 和を三角関数に渡すとき（`π + 1 = sin`）、`sin(π + 1) = −sin 1` と畳む手は使わない。f64 の `π + 1` の `sin` は 10 桁が合う（`-0.8414709848`）ので、畳む理由が無い。

## §4 後退しないための門

### §4.1 「f64 では表に載るのに、印を通すと外れる」入力は在るか

- **RAD では、構造上ない。** f64 の規則 `scientific::turn_of` は RAD で必ず `None` を返す（表を引かない）。RAD で表を引くのは印だけなので、印が増えても「f64 で引けていた表を失う」ことは起きない。
- **DEG では在る。1.2.4 の「表に吸う窓」がそのまま及ぶ。**
  - 例: DEG `π + 150 + 5 EXP 15 +/− = − π = sin − 0.5 =`。今は `0`、後は `-5.551115123e-17`（真値は `-7.557497351e-17`）。
  - 今は π を足した所で印が落ち、f64 の `(π + 150 + 5e-15) − π` が 150.0 ちょうどになって表に載る。後は印が `150 + 5e-15`（単項 k = 0）に戻り、1.2.4 の規則で決まる。
  - **同じ角を直接打った `150 + 5 EXP 15 +/− = sin − 0.5 =` は、1.2.4 から既に `-5.551115123e-17`** である（`the_table_window_is_half_an_ulp_of_the_offset`）。
  - 後では、打ち方（π を足して引いたか）で答えが変わらなくなる。真値にも近づく。**意図した変化として書く**（§5.1 の行）。
  - **乱択でこの形は「今合っているのに外れる」に数えていない。** 今の `0` も真値の 10 桁ではないからである。
- **k = 0 に戻った値の `re` の丸め直し**: 正しく丸めた f64 は、f64 の計算より真値から遠くない。10 桁の丸めの境目で表示が割れることはありうる。乱択では 0 本だった。
- **x^0.5 が `cancel` に入る**: 1.2.3 の 2 倍の門と書き換えを、`xʸ 0.5` の答えも通るようになる。
  - `2 xʸ 0.5 = − 1.4 =` は今も後も `0.01421356237`（門の外）。`3 xʸ 0.5 = − 3 √ =` は今も後も `0`。
  - 乱択では、`xʸ 0.5` の後に打った数を引く列で外れは 0 本だった。

### §4.2 数で示す根拠（試作）

| 測ったもの | 今合っているのに外れる | 違う→合う | 表示が動いた | 生の値が動いた |
|---|---:|---:|---:|---:|
| コーパス 25,339 件（表示は 10 桁と期待の文字列） | **0** | 0 | 0 | **0** |
| 乱択 19,331 本（表示は SymPy の真値の 10 桁） | **0** | **92** | 94 | 264 |

- **乱択で表示が動いた 94 本のうち、2 本は「違う→別の違う」である。** どちらも 1e15〜1e32 rad の巨大な角で、f64 の `sin` に意味が無い所である。
