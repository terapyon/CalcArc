## §1 今の外れ方（**e231550 で取り直した**）

台帳 §2 の 5 行は `d43cf71` の実測だった。`e231550` で取り直すと、表示は 5 行とも同じだった。

| 族 | キー列 | 今の表示 | 真値 |
|---|---|---|---|
| k = −1 | RAD `1 ÷ π = 1/x sin` | `1.224646799e-16` | `0` |
| k = 2 | RAD `π × π = ÷ π = sin` | `1.224646799e-16` | `0` |
| k が混ざる和 | RAD `π + 1 = − 1 = sin` | `1.224646799e-16` | `0` |
| √π | RAD `π √ x² sin` | `5.665538898e-16` | `0` |
| x^0.5 | `2 xʸ 0.5 = x² − 2 =` | `4.440892099e-16` | `0` |

**根は 1 つである。** 今の印は「有理数 × π^k（k は 0 か 1）」の**単項**しか持てない。印が落ちる所は 4 つある。
- **k が範囲の外へ出る**: `1 ÷ π`（k = −1）、`π × π` と `π x²`（k = 2）。
- **k の違う 2 つを足す**: `π + 1`。
- **√ の印 `Root` は k = 0 の正の有理数にしか付かない**: `π √` で落ちる。
- **`xʸ` は印を全部落とす**: `2 xʸ 0.5` に印が付かない。

一度落ちると、あとで π が消えても（`÷ π`、`− 1`、`1/x`、`x²`）戻らない。f64 の π で計算した角が三角関数に届く。

### §2.2 `Exact` の中身——**7 つの係数**

- **`re == q₋₂/π² + q₋₁/π + q₀ + q₁π + q₂π² + q₃π³ + q₄π⁴`**（虚部は問わない。今と同じ）。
- **正規化は要らなくなる。** 今の `(0, k=1)` を `(0, k=0)` に直す規則は、「全部 0」が 1 通りしか無い形に吸収される。
- **`Held::settled` が `re` を丸め直すのは、`q₀` 以外が 0 のときだけ**（今の「k = 0 のときだけ」と同じ意味）。π を含む値は今までどおり f64 の計算のままである。
- **「単項か」を読む関数を 1 つ置く**（`monomial() -> Option<(k, q)>`。全部 0 なら `(0, 0)`）。三角関数・`1/x`・`÷` の割る側・`√` が読む。k = 0 の単項だけを読む `rational() -> Option<Rational>` は `monomial` の上に置く（`Held::settled`・`signed_square`・`ln_near_one`・DEG の `turn` が読む）。

### §2.3 `Root`——**√ の中の π の冪を持つ。`Exact` とは混ぜない**

- **`Root { c, r }` に `pi: i8` を足す。** 意味は **`re == c × √(r × π^pi)`**。`pi` は −2〜4（√ を取る前の印の k）である。
- **作るのは `√` だけ**（`xʸ 0.5` は `√` を呼ぶ。§3.1）。引数の印が**単項 `(k, q)` で `q > 0`、実数**のとき:

  | k | `q` | 答えの印 |
  |---|---|---|
  | 0 | どれでも | **root `(1, q, 0)`**（今と同じ。平方数でも root のまま。下の「k = 0 の平方数」） |
  | 0 でない偶数（−2・2・4） | **平方数**（約分した分子と分母がどちらも平方数） | **`Exact` の単項 `(√q, k/2)`**（U1。`π x² √` は `π`、`π x² x² √` は `π²`、`π x² 1/x √` は `1/π`） |
  | 0 でない偶数 | 平方数でない | root `(1, q, k)`（`π x² × 2 = √` は `√2·π` の root） |
  | 奇数（−1・1・3） | どれでも | root `(1, q, k)`（`π √` は `(1, 1, 1)`、`1 ÷ π = √` は `(1, 1, −1)`） |

  - 0 は `(0, k=0)`（今と同じ）。負・和・印なし・複素は落とす。
  - **平方数の判定は整数の平方根で厳密に行う**（`u128::isqrt`。1.84 から在る。f64 の `sqrt` で当てない）。
- **読むのは今のまま 2 か所。**
  - **`x²`**: root `(c, r, pi)` を単項 `(c²r, pi)` にして返す。`pi` は −2〜4 なので、**範囲の外へは出ない**。`π √ x²` は `π` に、`1 ÷ π = √ x²` は `1/π` に戻る。
  - **`cancel`**（√ の和・差の書き換え。下の「F1 の門」）。
- **`Root` を `Exact` の係数に混ぜない理由**: √ は多項式の外の数である（`√2` も `√π` も、π の有理係数の和では書けない）。混ぜるなら「√ の中身 × π の多項式」の 2 段の形が要るが、直る行は今の形で直る。

**範囲の端（U1 × U2）**。**`√` は範囲の外へ出さない**——k ∈ [−2, 4] の √ は、root なら `pi = k`、平方数なら単項 `k/2 ∈ {−1, 1, 2}` で、どちらも範囲の中である。**外へ出るのは `×`・`÷`・`x²`・`1/x` の積だけ**で、そのときは印を全部落とす（§3.1）。

| キー列（RAD） | 途中の印 | 後の答え |
|---|---|---|
| `π x² x² √ √ sin` | π⁴ → √ で π² → √ で π | `0`（今 `1.224646799e-16`） |
| `π x² 1/x √ 1/x sin` | π⁻² → √ で π⁻¹ → `1/x` で π | `0`（今 `1.224646799e-16`） |
| `π × π = × π = √ x² ÷ π = ÷ π = sin` | π³ → root `(1, 1, 3)` → `x²` で π³ | `0`（今 `1.224646799e-16`） |
| `π x² x² × π = ÷ π = …` | π⁴ × π = π⁵ は**外**→ 落とす | `÷ π` を 4 回で `1.224646799e-16` のまま |
| `π x² x² x² √ √ √ sin` | π⁴ の `x²` = π⁸ は**外**→ 落とす | `1.224646799e-16` のまま |
| `π x² 1/x ÷ π = × π = …` | π⁻² ÷ π = π⁻³ は**外**→ 落とす | `× π` を 4 回で `5.665538898e-16` のまま |

**F1 の門（`A²/4 ≤ B² ≤ 4A²`）との相互作用——門が見る組は 1.2.3 から変わらない（x^0.5 を除く）**。
- `cancel` が書き換えるのは「**片方が `pi = 0` の root で、もう片方が `pi = 0` の root か、k = 0 の単項の `Exact`**」の組だけである。`signed_square` が、root では `pi == 0`、`Exact` では `rational()`（単項 k = 0）でなければ `None` を返す。
- **U1 で `Exact` に戻る値は、k = 0 にならない**（k/2 は −1・1・2）。だから門には入らない。`π x² √ − π =` は `cancel` ではなく `sub` の印が厳密に引いて `0` である。
- **`pi ≠ 0` の root は門に入らない。** `π x² × 2 = √ − π = sin` は f64 の差のまま `0.9639025328`（今も同じ）。π の √ どうしの差を書き換える式は 1.2.3 の門の根拠（有理数の 2 乗で比べる）が使えないので、作らない。
- **k = 0 の √ は平方数でも root のまま**にする（`4 √` は今と同じ root `(1, 4, 0)`）。**直す族ではなく、1.2.3 の root の意味（k = 0 の √ は root）を変えないため**である。
  - `Exact` に戻しても損は無い（`4 √ − 2 =` は `cancel` の代わりに `sub` の印が引いて同じ `0`）が、1.2.3 の規則と番人を書き換える理由がこの版には無い。
  - **だから綴りで答えが割れる。** `4 √ × π = sin` は root と π の積で印が落ち、今のまま `-2.449293598e-16`。`π x² × 4 = √ sin` は `√(4π²) = 2π` の単項で `0`。どちらも範囲どおりで、§5.1 で両方を留める。
- **門に新しく入るのは `xʸ 0.5` の答えだけ**である（§4.1、条件 1）。

### §2.4 `STATE_SCHEMA` は 10 → 11、i128 の溢れ、直列化の大きさ

- **`Exact` の直列化の形が変わる。** 今は `{ "q": "n/d", "pi": bool }`。後は、7 つの係数を k = −2, …, 4 の順に並べた文字列の列 `{ "terms": ["n/d", …] }`（7 個ちょうど）にする（綴りは実装が決める）。**有理数を文字列で渡す 1.2.2 §6.1 の規則は保つ。** 個数が 7 でなければ読みが失敗する。

## §3 どの演算で印を保ち、どこで捨てるか

### §3.1 演算ごとの規則

| キー | 今（e231550） | 後 |
|---|---|---|
| 打った数・`π`・`0`・表の答え | 単項 k = 0 か 1 | 同じ（係数の 1 つだけが 0 でない） |
| `+`・`−` | k が同じか片方が 0 なら和、違えば落とす | **係数ごとの和**。溢れたら落とす。`cancel` は §2.3 のとおり |
| `×` | k の和が 1 以下なら積、2 なら落とす | **多項式の積**。積の項が 1 つでも k ∈ [−2, 4] の外に出たら落とす。複素なら落とす（今と同じ） |
| `÷` | 割る側が k = 0、または両方 k = 1 | **割る側が単項 `(k, q)`、`q ≠ 0` のとき、割られる側の各項 `qᵢπ^i` を `(qᵢ/q)π^(i−k)` にする**。1 項でも範囲の外へ出たら落とす。**割る側の逆数 `π^−k` は作らない**——作ると、割る側が k = 3・4 のとき逆数が範囲の外に出て、答えが範囲の中でも落ちる（`π x² x² ÷ ( π x² × π ) =` は π。§5.1）。**`0 ÷ x` は 0**（今と同じ）。**0 ÷ b（b ≠ 0）は、割る側を見る前に 0 を先に見る**——割る側が和でも答えは 0。割る側が和（`÷ (π + 1)`）で割られる側が 0 でなければ落とす |
| `+/−` | `(−q, k)`、root は `(−c, r)` | 係数ごとに符号を反転する。root は `(−c, r, pi)` |
| `x²` | k = 0 なら `q²`、root なら `c²r`、k = 1 は落とす | **自分との積**（`π x²` は k = 2、`(π + 1) x²` は `π² + 2π + 1`、π³ の `x²` は外で落とす）。root は単項 `(c²r, pi)` |
| `1/x` | k = 0 で 0 でなければ `1/q` | **単項なら `(1/q, −k)`**。範囲の外（k = 3・4 の逆数）なら落とす。和なら落とす |
| `√` | k = 0 の `q > 0` で root `(1, q)`、0 は 0 | **§2.3 の表**。単項で `q > 0` なら、k = 0 は root `(1, q, 0)`、0 でない偶数で平方数は単項 `(√q, k/2)`、それ以外は root `(1, q, k)`。0 は 0。和・負は落とす |
| `xʸ` | 落とす | **指数の印がちょうど k = 0 の `1/2` で、底と指数が実数なら、`√` と同じ印**（U1 も含む。`π x² xʸ 0.5` は `π`）。それ以外は落とす（整数の指数は範囲外。§7） |
| `sin`・`cos`・`tan` | §3.2 | §3.2 |
| `ln`・`log`・`eˣ`・`n!`・`nPr`・`nCr`・逆三角関数 | 落とす | 同じ |

**`xʸ 0.5` の値も `√` で計算する。**
- `x.powf(0.5)` と `x.sqrt()` は、打った 20,000 個の十進のうち 13 個で 1 ビット違った（この作業機のネイティブ）。√ は正しく丸めるが、`powf` はそうとは限らない。
- root を持つ値の `re` は「√ の f64」である（`Held::settled` の註、1.2.3 §3.1）。`powf` の値のまま印だけ付けると、この不変が x^0.5 で嘘になる。
- 計算を √ にそろえても、コーパスの表示と生の値は 1 件も動かなかった（`xʸ 0.5` が 0 本）。
- **定義域の誤り（負の底）は、今の `scientific::pow` を先に呼んで出す**（1.2.3 の `apply_log` と同じ順）。

### §3.2 三角関数——**角を決める規則は増やさない**

| 角度 | 引数の印 | 角の正体 |
|---|---|---|
| RAD | **単項 k = 1**（`qπ`） | `pi_turn(q)`。表か、`(−1, 1]` に畳んだ角（今と同じ関数） |
| RAD | ちょうど 0 | 表の 0（今と同じ） |
| RAD | それ以外（k ≠ 1 の単項・和・0 でない k = 0） | 表を引かない。f64 の値の `sin`・`cos`（今と同じ。`turn_of` は RAD で表を引かない） |
| DEG | **単項 k = 0** | `degree_turn(q)`（1.2.4 の規則） |
| DEG | それ以外 | f64 の規則（`turn_of`。今と同じ） |

**変わるのは「単項 k = 1」「単項 k = 0」に届く道が増えることだけ**で、角を決める関数は 1 行も変えない。
- 和を三角関数に渡すとき（`π + 1 = sin`）、`sin(π + 1) = −sin 1` と畳む手は使わない。f64 の `π + 1` の `sin` は 10 桁が合う（`-0.8414709848`）ので、畳む理由が無い。
- root は三角関数が読まない（今と同じ）。`π √ sin` は f64 の `√π` の `sin`。

## §4 後退しないための門

### §4.1 「f64 では合うのに、印を通すと変わる」入力は在るか

- **RAD の表は、構造上失わない。** f64 の規則 `scientific::turn_of` は RAD で必ず `None` を返す（表を引かない）。RAD で表を引くのは印だけなので、印が増えても「f64 で引けていた表を失う」ことは起きない。
- **DEG では在る。1.2.4 の「表に吸う窓」がそのまま及ぶ（U4、受け入れ済み）。**
  - 例: DEG `π + 150 + 5 EXP 15 +/− = − π = sin − 0.5 =`。今は `0`、後は `-5.551115123e-17`（真値は `-7.557497351e-17`）。
  - 今は π を足した所で印が落ち、f64 の `(π + 150 + 5e-15) − π` が 150.0 ちょうどになって表に載る。後は印が `150 + 5e-15`（単項 k = 0）に戻り、1.2.4 の規則で決まる。
  - **同じ角を直接打った `150 + 5 EXP 15 +/− = sin − 0.5 =` は、1.2.4 から既に `-5.551115123e-17`** である（`the_table_window_is_half_an_ulp_of_the_offset`）。打ち方で答えが変わらなくなり、真値にも近づく。
  - **乱択でこの形は「今合っているのに外れる」に数えていない。** 今の `0` も真値の 10 桁ではないからである。
- **k = 0 に戻った値の `re` の丸め直し**: 正しく丸めた f64 は、f64 の計算より真値から遠くない。10 桁の丸めの境目で表示が割れることはありうる。乱択では 0 本だった。
- **x^0.5 が `cancel` に入る（レビュー役の条件 1）**。`xʸ 0.5` の答えに root の印が付くので、1.2.3 の 2 倍の門と書き換えを通るようになる。**利用者に見える変化である。**

  - **門の外は動かない**: `2 xʸ 0.5 = − 0.5 =` は今も後も `0.9142135624`（A² = 2、B² = 0.25。4B² = 1 < A²）。

  - `3 xʸ 0.5 = − 3 √ =` は今も後も `0`（後は root どうしの書き換えで分子が 0）。

- **√(π²) が単項に戻る（U1）のは、表示を変えるだけで門には入らない**（§2.3 の「F1 の門」）。

### §5.2 単体テストと境界

- **`exact.rs`**: §4.2 の 12 本を新しい規則に書き換える。足すのは次のとおり。

  - `Exact` の今の `pub fn q()`・`pub fn pi()` は、`exact.rs` の外では `engine/mod.rs` の `ln_near_one` だけが使う（クレートの外と `calcarc-wasm` は 0 か所）。`pub(super)` の `rational()`・`monomial()` に置き換える。**pub の面は 2 つ減る。**
  - `Exact::of`（pub）は単項を作る関数として残す（テストと `table_answer` が使う）。
  - `Root` の欄は今と同じく private にする。
- **MSRV 1.87 で書く。ただし番人ではない**（レビュー役の注記）。`Cargo.toml` は `rust-version = "1.87"` と宣言しているが、`exact.rs` の `pi_turn` に let チェーン（1.88 から）がすでにあり、CI は 1.87 で build しない。だから「1.87 で通る」は守る規律であって、破っても赤くならない。
  - 新しいコードには let チェーンを書かない。`u128::isqrt`（1.84）・配列の `map`・`let … else` は 1.87 より前から在る。
  - 番人を置くか（CI に 1.87 の build を 1 段足す、既存の let チェーンを書き換える）は、この版の範囲の外である。台帳に載せる。
- **包むだけの関数を作らない。** `monomial` は 4 か所以上が読むので置く。`rational` は `monomial` の上の 1 行だが、読む所が 4 か所ある。`zip`・`product` のような共通の手続きは、四則の 4 本が使うときだけ置く。
- **註に作業の経緯を書かない。** 「試作で測った」「1.2.4 までは」の類いは、この設計書と台帳に置く。
- **新しい依存を足さない。** 試作のコードを写さない（§0）。

## §10 この設計書が断定しないこと
